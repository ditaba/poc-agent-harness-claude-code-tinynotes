# TinyNotes – agent progress log

## Codebase patterns

Reusable learnings for later tasks, one line each: API quirks, verified commands, conventions.
ralph.ts gives every iteration this section, so record here what you would otherwise look up again.

- Prettier config is `.prettierrc` with `prettier-plugin-tailwindcss` + `"tailwindStylesheet": "./app/globals.css"` (Tailwind v4 needs the stylesheet path for class sorting).
- `bun run typecheck`/`next build` can fail on stale `.next/types/validator.ts` or `.next/dev/types/validator.ts` from deleted routes; `rm -rf .next` then rebuild.
- Windows: Bash tool is Git Bash; use `> .ralph/check.log 2>&1; echo "exit=$?"` for checks. `bun test` with no test files exits 1 (expected until M1).
- better-auth 1.7.7 CLI: `bunx --bun auth@1.7.7 generate --config <file> --output <file> --yes` (package is `auth`; `--bun` so the config can import `bun:sqlite`). `betterAuth({ database: new Database(path) })` needs no adapter option.
- better-auth rate limiter works under `bun --bun next start` with only `rateLimit.customRules` (no `advanced.ipAddress`); it is off in `next dev`. Every request to the path counts (successes and 403s too), so restart the server before a clean 429 test.
- Stop a server on port 3000 from Git Bash: `powershell -NoProfile -Command "Get-NetTCPConnection -LocalPort 3000 -State Listen | % { Stop-Process -Id \$_.OwningProcess -Force }"`.
- `bun:sqlite` `db.run(sql)` executes a multi-statement .sql file (no params); DDL inside `db.transaction()` rolls back fully on error (verified in lib/migrate.test.ts).
- Bun auto-loads `.env` for `bun scripts/*.ts`, so scripts/migrate.ts reads env via process.env with no dotenv; insertTestUser(db, email?) from lib/testing/db.ts is the user fixture for DB tests.
- `@tiptap/static-renderer` 3.31 html-string output: `<br/>` self-closing, `<ol>` without `start` attr when absent, codeBlock emits `<pre><code class="language-…">`.
- bun:sqlite UPDATE `.run().changes` counts matched rows even when values are unchanged, so disableShare on a private owned note returns true (D42).
- TipTap 3.31 server validation: `Node.fromJSON(getSchema(editorExtensions), json)` throws RangeError on unknown node/mark types and silently drops unknown attrs; `toJSON()` adds default attrs (e.g. heading level), so normalized JSON can be larger than input. Bash heredocs with nested quotes can break on Windows Git Bash; use the Write tool for new files.
- better-auth 1.7.7 sign-up duplicate email throws `BASE_ERROR_CODES.USER_ALREADY_EXISTS_USE_ANOTHER_EMAIL` (422; `node_modules/better-auth/dist/api/routes/sign-up.mjs`). better-call VALIDATION_ERROR message is `[body.<field>] <msg>` joined by `; ` for several issues.
