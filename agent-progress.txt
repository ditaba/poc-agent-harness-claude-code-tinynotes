# TinyNotes – agent progress log

## Codebase patterns

Reusable learnings for later tasks, one line each: API quirks, verified commands, conventions.
ralph.ts gives every iteration this section, so record here what you would otherwise look up again.

- Prettier config is `.prettierrc` with `prettier-plugin-tailwindcss` + `"tailwindStylesheet": "./app/globals.css"` (Tailwind v4 needs the stylesheet path for class sorting).
- `bun run typecheck`/`next build` can fail on stale `.next/types/validator.ts` or `.next/dev/types/validator.ts` from deleted routes; `rm -rf .next` then rebuild.
- Windows: Bash tool is Git Bash; use `> .ralph/check.log 2>&1; echo "exit=$?"` for checks. `bun test` with no test files exits 1 (expected until M1).
- better-auth 1.7.7 CLI: `bunx --bun auth@1.7.7 generate --config <file> --output <file> --yes` (package is `auth`; `--bun` so the config can import `bun:sqlite`). `betterAuth({ database: new Database(path) })` needs no adapter option.
- better-auth rate limiter works under `bun --bun next start` with only `rateLimit.customRules` (no `advanced.ipAddress`); it is off in `next dev`. Every request to the path counts (successes and 403s too), so restart the server before a clean 429 test.
- Stop a server on port 3000 from Git Bash: `powershell -NoProfile -Command "Get-NetTCPConnection -LocalPort 3000 -State Listen | % { Stop-Process -Id \$_.OwningProcess -Force }"`.
- `bun:sqlite` `db.run(sql)` executes a multi-statement .sql file (no params); DDL inside `db.transaction()` rolls back fully on error (verified in lib/migrate.test.ts).
- Bun auto-loads `.env` for `bun scripts/*.ts`, so scripts/migrate.ts reads env via process.env with no dotenv; insertTestUser(db, email?) from lib/testing/db.ts is the user fixture for DB tests.
- `@tiptap/static-renderer` 3.31 html-string output: `<br/>` self-closing, `<ol>` without `start` attr when absent, codeBlock emits `<pre><code class="language-…">`.
- bun:sqlite UPDATE `.run().changes` counts matched rows even when values are unchanged, so disableShare on a private owned note returns true (D42).
- TipTap 3.31 server validation: `Node.fromJSON(getSchema(editorExtensions), json)` throws RangeError on unknown node/mark types and silently drops unknown attrs; `toJSON()` adds default attrs (e.g. heading level), so normalized JSON can be larger than input. Bash heredocs with nested quotes can break on Windows Git Bash; use the Write tool for new files.
- better-auth 1.7.7 sign-up duplicate email throws `BASE_ERROR_CODES.USER_ALREADY_EXISTS_USE_ANOTHER_EMAIL` (422; `node_modules/better-auth/dist/api/routes/sign-up.mjs`). better-call VALIDATION_ERROR message is `[body.<field>] <msg>` joined by `; ` for several issues.
- Playwright MCP: run a whole checklist flow in one browser_run_code_unsafe call (fill, click, read role=status/alert textContent); `page.route("**/api/auth/**", r => r.abort())` simulates a network failure. authClient returns `{ error }` for HTTP errors; AuthForm still wraps it in try/catch for thrown fetch errors.
- Playwright selectors: scope to `main` (`main button[type=submit]`, `main [role=alert]`); in dev the Next devtools button and the always-present `#__next-route-announcer__` (role=alert) break strict-mode `getByRole`.
- Playwright MCP tab can go stale after HMR rebuilds (viewportSize() null, clicks dispatch no DOM events); run the flow in `const p = await page.context().newPage()` instead.
- Use a throwaway DB for manual checks: `DB_PATH=data/m4-test.db bun run dev` (process env beats .env); delete `data/m4-test.db*` afterwards.
- Next 16 error.tsx: `reset()` only clears boundary state (no refetch); `retry()` / `catchError` from `next/error` also refreshes. SPEC wants `reset()`, which recovers fine from a failed form action.
- Layout: every page `<main>` and the AppHeader inner div use the `page-container` utility (`@utility` in app/globals.css, max-w-3xl + px-4); focus rings come from the global `:focus-visible` rule in `@layer base`, so new controls need no focus classes. Light theme only: no `dark:` variants.
- Next 16 `PageProps<"/notes/[id]">` (global, params is a Promise) only typechecks after `next build`/`next dev` generates route types; run typecheck after build for new routes.
- Tailwind 4 `@theme inline` vars (e.g. `--font-mono`) are not emitted as CSS variables; in plain CSS use `var(--font-geist-mono)` and `var(--color-zinc-*)` (those exist).
- Playwright paste into TipTap: `el.dispatchEvent(new ClipboardEvent("paste", { clipboardData: dt, bubbles: true, cancelable: true }))` with a `DataTransfer` holding text/plain (works for 2 MB); count POSTs with `p.on("request")` to prove no action call.
- Playwright: test a Server Action with a foreign id by rewriting the POST body in `page.route` (`route.continue({ postData: body.replace(ownId, otherId) })`); replaying a captured action POST via `context.request` returns the HTML 404 page instead.
- Playwright clipboard: `ctx.grantPermissions(["clipboard-read","clipboard-write"], { origin })` then `navigator.clipboard.readText()`; read button labels with `locator(":has-text('Copied!')").waitFor()`, not innerText right after click (the write is async).
- Playwright treats `aria-disabled="true"` buttons as not enabled; use `click({ force: true })` to test that they do nothing. Click the text (`ed.getByText(...)`) to place the cursor, not `ed.click()` (StarterKit TrailingNode adds an empty paragraph after headings/code blocks, and the centre of the min-h-64 editor lands there).
- TipTap 3.31 toolbar state: `useEditorState({ editor, selector })` returning an array of `{ pressed, enabled }` stays fresh; `enabled` = `command(editor.can().chain()).run()`, run = `command(editor.chain().focus()).run()`; `onMouseDown` preventDefault keeps the editor selection.
