Findings (M2 main risk, TipTap 3.31.4 / prosemirror-model 1.25.12):
- getSchema(editorExtensions) works in Bun with no DOM and no Editor. Nodes: doc, paragraph, text, heading,
  blockquote, bulletList, orderedList, listItem, codeBlock, hardBreak. Marks: bold, italic, strike, code. No link,

  on empty text nodes. It drops unknown attrs on nodes and marks and fills defaults. It does NOT check content

- No attr has a `validate` function, so attr values aren't type-checked: a heading level outside [2, 3] (or any
  value) is stored as given. TipTap's Heading renderHTML falls back to levels[0] (h2) for such levels, so PUB-4
  still holds. codeBlock language is an arbitrary string, which M2-render's escaping test covers (R4).
- Mutation runs also confirmed the byte-count test fails with .length, the growth test fails if size is checked
  on the raw input, and the trim tests fail without trim().
